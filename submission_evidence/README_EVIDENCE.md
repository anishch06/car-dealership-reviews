# Evidence files — sample format only

The text files in this folder are **illustrative sample outputs**. Run the commands against your own local server and replace these samples with your real output before submission.

- `django_server`: local Django server startup sample
- `loginuser`, `logoutuser`: cURL examples and sample responses
- `getdealerreviews`, `getalldealers`, `getdealerbyid`, `getdealersbyState`, `getallcarmakes`, `analyzereview`: API examples and sample responses
- `deploymentURL`: intentionally a placeholder; replace only after real deployment
- `CICD`: example workflow log format, not proof of a successful GitHub Actions run
